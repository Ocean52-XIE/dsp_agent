# Knowledge QA

## 什么时候使用

当内置路由规则判断问题属于知识问答时，使用本 skill。

典型场景：
- 某个模块是做什么的
- 某条链路怎么走
- 指标和口径是什么意思
- 某个函数在哪个文件
- 某个实现入口在哪里

## 执行规则

1. 如果答案需要证据支撑，调用 `domain_retrieve`
2. 当问题涉及代码位置、函数、文件、类、参数时，优先使用 `code_first`
3. 当问题涉及概念、架构、流程、业务说明时，优先使用 `wiki_first`
4. 证据不足时要明确说明，而不是补充猜测
5. 回答必须能落到具体证据来源

## 推荐输出结构

```text
结论

依据

涉及模块 / 文件

补充说明
```

## 引用要求

- 如果 tool 返回了 `citations`，优先基于这些引用组织回答
- 不要编造文件路径、章节名和函数名
- 若无法确认实现位置，要明确说明“当前证据不足以定位”
