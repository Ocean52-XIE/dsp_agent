# Eval Model Network

## 什么时候使用

当用户请求评估模型网络结构时，使用本 skill。

典型触发场景：
- "帮我评估模型 id {xx} 的网络结构是否存在问题"
- "检查模型 {xx} 的结构有没有问题"
- "分析一下 {xx} 模型的网络设计"
- "评估 {xx} 模型结构是否合理"

## 执行规则

1. 首先从用户输入中提取模型 ID（model_id）
2. 调用 `get_model_network` 工具，传入 model_id 参数
3. 根据返回的模型结构信息，从以下维度进行分析：
   - **输入输出一致性**：输入维度与首层是否匹配，输出维度是否符合预期
   - **层级连接**：相邻层的输入输出通道数是否匹配，是否缺少loss函数、激活函数等关键组件
   - **激活函数使用**：是否在合适的位置使用了激活函数
   - **归一化层**：是否合理使用了 BatchNorm/LayerNorm
   - **参数量**：模型规模是否合理，是否存在过大或过小的情况
   - **潜在问题**：梯度消失/爆炸风险、过拟合风险等
4. 给出结构化的评估结论和改进建议

## 工具调用示例

```json
{
  "tool": "get_model_network",
  "arguments": {
    "model_id": "resnet50"
  }
}
```

## 注意事项

- 如果模型 ID 不存在，工具会返回可用模型列表，应告知用户并建议使用正确的模型 ID
- 对于不同类型的模型（classification、transformer 等），评估重点应有所区别
- 评估结论应基于模型结构数据，避免主观臆断
