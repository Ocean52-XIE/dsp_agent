# 广告文案创作最佳实践

## 标题创作技巧

### 1. 数字法则
- 使用具体数字增加可信度
- 例：「7天瘦5斤」「3步搞定」「99%用户推荐」

### 2. 疑问句式
- 引发用户好奇心
- 例：「为什么都在用？」「你还不知道？」

### 3. 对比手法
- 前后对比突出效果
- 例：「从0到1」「告别XX，拥抱YY」

### 4. 痛点切入
- 直接点出用户困扰
- 例：「还在为XX烦恼？」「XX问题一键解决」

## 正文创作要点

### 结构公式：AIDA
1. **Attention**（注意）：抓住眼球
2. **Interest**（兴趣）：引发兴趣
3. **Desire**（欲望）：激发需求
4. **Action**（行动）：引导转化

### 常用句式
- 「如果你...那么...」
- 「不是...而是...」
- 「既能...又能...」
- 「X小时/天，实现Y」

## 行动号召（CTA）设计

### 高转化CTA词汇
- 立即、马上、现在
- 免费、限时、专属
- 领取、体验、试用
- 了解更多、查看详情

### CTA位置
- 正文结尾处
- 突出显示
- 与正文形成视觉区隔

## 不同平台文案规范

| 平台 | 标题字数 | 正文字数 | 特殊要求 |
|------|---------|---------|---------|
| 信息流 | 15-25 | 40-80 | 自然融入内容流 |
| 搜索 | 25-30 | 60-80 | 关键词前置 |
| 视频 | 15-20 | 50-100 | 配合画面节奏 |
| 横幅 | 8-15 | 无 | 极简突出 |
| 社交 | 20-40 | 100-200 | 可用表情标签 |

## 避坑指南

1. **避免夸大宣传**：不符合实际的承诺会降低信任
2. **避免模糊表达**：具体比笼统更有说服力
3. **避免负面词汇**：正面表达转化率更高
4. **避免专业术语堆砌**：用户看不懂的文案无效
