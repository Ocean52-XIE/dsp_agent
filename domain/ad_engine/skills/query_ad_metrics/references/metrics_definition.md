# 广告指标定义参考

## 核心指标

### CTR（点击率）

**定义**：广告被点击的次数与展示次数的比率。

**计算公式**：
```
CTR = 点击量 / 展示量 × 100%
```

**正常范围**：1.5% - 3.5%

**影响因素**：
- 创意质量
- 定向精准度
- 出价策略
- 竞价环境

### CVR（转化率）

**定义**：用户完成转化行为的次数与点击次数的比率。

**计算公式**：
```
CVR = 转化量 / 点击量 × 100%
```

**正常范围**：2% - 8%

**影响因素**：
- 落地页质量
- 商品/服务吸引力
- 转化链路设计
- 用户匹配度

### eCPM（千次展示收益）

**定义**：每千次广告展示产生的预期收益。

**计算公式**：
```
eCPM = CTR × CVR × 转化价值 × 1000
```

**用途**：排序竞价的核心指标

## 指标异常排查

| 异常现象 | 可能原因 | 排查方向 |
|---------|---------|---------|
| CTR 骤降 | 创意疲劳、定向漂移 | 检查创意轮播、人群包更新 |
| CVR 骤降 | 落地页问题、回传延迟 | 检查落地页加载、转化回传 |
| 消耗突增 | 出价过高、流量异常 | 检查出价配置、流量质量 |
| 展示量下降 | 竞价失败、预算不足 | 检查胜率、预算状态 |
