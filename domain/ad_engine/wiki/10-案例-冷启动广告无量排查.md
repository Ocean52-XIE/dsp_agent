# 案例：冷启动广告无量排查

> **模块**: ad-recall, rate-prediction
> **标签**: 排障案例、冷启动、新广告、无量
> **关键词**: 冷启动、新广告、无量、曝光、cold_start、new_ad

## 问题现象

新建广告计划/创意出现"无量"问题：
- 广告审核通过后无曝光
- 冷启动期间消耗极低
- 系统提示"建议提升出价"但出价已很高
- 填充率接近 0%

## 排查步骤

### 1. 确认广告状态

首先确认广告基础配置是否正确：

```python
# 检查广告状态
ad_status = get_ad_status(ad_id)
print(f"审核状态: {ad_status.audit_status}")
print(f"投放状态: {ad_status.delivery_status}")
print(f"预算状态: {ad_status.budget_status}")
```

### 2. 检查召回阶段

检查广告是否被成功召回：

```python
# 检查召回日志
recall_logs = get_recall_logs(ad_id, time_range="1h")
print(f"召回次数: {recall_logs.recall_count}")
print(f"召回后过滤: {recall_logs.filtered_count}")

# 检查过滤原因
if recall_logs.filtered_count > 0:
    print("过滤原因分布:")
    print(recall_logs.filter_reasons)
```

常见过滤原因：
- 定向不匹配
- 频控超限
- 预算不足
- 时间段限制

### 3. 检查两率预估

冷启动广告由于缺乏历史数据，两率预估可能偏低：

```python
# 检查冷启动广告的两率预估
pctr, pcvr = predict_ctr_cvr(ad_id, user_id)
print(f"pCTR: {pctr:.4f}")
print(f"pCVR: {pcvr:.4f}")

# 对比平均水平
avg_pctr = get_average_pctr()
print(f"平均 pCTR: {avg_pctr:.4f}")
```

### 4. 检查出价竞争力

```python
# 检查出价是否具有竞争力
bid = compute_bid_for_request(ad_id, request)
print(f"当前出价: {bid}")

# 获取同广告位竞争出价分布
competing_bids = get_competing_bids(slot_id)
print(f"竞争中位出价: {competing_bids.median}")
print(f"出价百分位: {competing_bids.get_percentile(bid)}")
```

### 5. 检查分层保底策略

检查是否有冷启动保底策略：

```python
# 检查冷启动配置
cold_start_config = get_cold_start_config()
print(f"探索流量配额: {cold_start_config.exploration_quota}")
print(f"内容相似召回: {cold_start_config.content_similarity_recall}")
print(f"分层保底策略: {cold_start_config.tiered_fallback}")
```

## 常见原因

| 原因 | 占比 | 症状 |
|------|------|------|
| 两率预估过低 | 35% | pCTR/pCVR 明显低于平均 |
| 定向过窄 | 25% | 召回量极少 |
| 出价竞争力不足 | 20% | 出价百分位 < 30% |
| 缺少探索流量 | 15% | 无冷启动扶持 |
| 特征缺失 | 5% | 新广告特征不完整 |

## 解决方案

### 方案一：冷启动预估校准

```python
# rate_predictor.py
def cold_start_calibration(pctr, ad_age):
    """冷启动广告的预估校准"""
    if ad_age < COLD_START_THRESHOLD:
        # 给予冷启动广告预估加成
        boost_factor = 1.0 + (COLD_START_THRESHOLD - ad_age) * 0.01
        pctr = min(pctr * boost_factor, 1.0)
    return pctr
```

### 方案二：分配探索流量

```python
# ad-recall 模块
# 为冷启动广告分配一定比例的探索流量
def allocate_exploration_quota(candidates):
    cold_start_ads = [c for c in candidates if c.is_cold_start]
    regular_ads = [c for c in candidates if not c.is_cold_start]

    # 保底 20% 流量给冷启动广告
    cold_start_quota = max(len(candidates) * 0.2, len(cold_start_ads))
    return cold_start_ads[:cold_start_quota] + regular_ads
```

### 方案三：内容相似召回

```python
# 利用广告内容特征进行相似召回
def content_similarity_recall(new_ad, top_k=100):
    """基于内容相似度的冷启动召回"""
    new_ad_embedding = get_content_embedding(new_ad)
    similar_users = find_similar_user_segments(new_ad_embedding)
    return similar_users[:top_k]
```

### 方案四：建议用户调整

向广告主提供优化建议：
- 扩大定向范围
- 适当提升出价
- 丰富广告素材
- 延长观察周期
