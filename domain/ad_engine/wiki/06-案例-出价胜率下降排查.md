# 案例：出价胜率下降排查

> **模块**: bid-optimizer
> **标签**: 排障案例、出价、胜率
> **关键词**: 出价、胜率、下降、排查、bid、winrate

## 问题现象

广告主或运营反馈出价胜率（Win Rate）出现明显下降，例如：
- 胜率从 35% 下降到 20%
- 竞价成功率持续走低
- 成本无明显变化但曝光量减少

## 排查步骤

### 1. 确认数据准确性

首先确认胜率下降是否为真实情况：
- 检查数据统计口径是否有变更
- 确认时间窗口是否合理（避免节假日等特殊时段）
- 对比历史同期数据

### 2. 检查两率预估

检查 pCTR/pCVR 预估是否正常：

```python
# 查看 rate_predictor.py 的预估输出
# 确认两率预估值分布是否正常
```

常见问题：
- 预估值整体偏高或偏低
- 特定人群/场景预估值异常

### 3. 确认 Pacing 策略

检查预算节奏控制（Pacing）是否有变更：
- Pacing 系数是否过于保守
- 是否有新的 Pacing 策略上线
- 预算消耗曲线是否正常

### 4. 排查竞对出价变化

分析市场竞争环境：
- 是否有新竞对进入
- 竞对出价是否整体抬升
- 流量竞争激烈程度变化

### 5. 检查出价参数

检查 `bid_optimizer.py` 中的关键参数：
- alpha 系数是否正确
- 目标 CPA/ROAS 配置是否合理
- 出价上下限是否有调整

## 常见原因

| 原因 | 占比 | 排查方式 |
|------|------|---------|
| 竞对出价抬升 | 40% | 分析竞对出价分布 |
| 两率预估偏低 | 25% | 检查预估值分布 |
| Pacing 过于保守 | 20% | 检查 Pacing 系数 |
| 目标配置错误 | 10% | 检查 target_cpa/target_roas |
| 其他 | 5% | 日志分析 |

## 解决方案

### 方案一：调整 Alpha 系数

```python
# bid_optimizer.py
# 适当提高 alpha 系数以提升出价竞争力
alpha = compute_alpha(...) * 1.1  # 提升 10%
```

### 方案二：优化 Pacing 策略

- 放宽 Pacing 限制，允许更激进的出价
- 调整预算消耗节奏参数

### 方案三：校准两率预估

- 重新训练预估模型
- 调整校准参数
