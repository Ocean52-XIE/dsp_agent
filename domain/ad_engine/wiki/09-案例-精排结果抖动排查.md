# 案例：精排结果抖动排查

> **模块**: rerank-engine
> **标签**: 排障案例、精排、抖动、稳定性
> **关键词**: 精排、抖动、不稳定、排序、rerank、rank_score

## 问题现象

精排结果出现明显抖动：
- 相同请求排序结果不一致
- 广告位次频繁变化
- 用户刷新后结果差异大
- 排序分数波动明显

## 排查步骤

### 1. 确认抖动范围

首先确认抖动的范围和频率：
- 是否为偶发抖动（可接受）
- 是否为持续抖动（需排查）
- 是否为特定场景抖动

```python
# 统计排序稳定性
def check_ranking_stability(request_id, n_samples=10):
    """检查同一请求多次排序结果的一致性"""
    results = []
    for _ in range(n_samples):
        result = execute_ranking(request_id)
        results.append(result)

    # 计算 Kendall's Tau 一致性
    consistency = calculate_kendall_tau(results)
    return consistency
```

### 2. 检查实时特征

实时特征波动是精排抖动的最常见原因：

```python
# 检查实时特征分布
realtime_features = get_realtime_features(request_id)
for feature, value in realtime_features.items():
    if feature.endswith("_rate"):
        # 检查实时率值类特征
        print(f"{feature}: {value}")
```

常见问题特征：
- 实时点击率特征波动
- 用户兴趣标签变化
- 上下文特征不稳定

### 3. 检查探索机制

检查是否有探索/实验机制导致抖动：

```python
# rerank_engine.py
# 检查探索权重
exploration_rate = get_exploration_rate()
if exploration_rate > 0.1:
    print(f"探索权重过高: {exploration_rate}")
```

### 4. 检查多约束冲突

多约束排序可能导致结果不稳定：

```python
# 检查约束条件
constraints = {
    "diversity": get_diversity_penalty(),
    "safety": get_safety_penalty(),
    "frequency": get_frequency_penalty(),
}

# 如果多个约束同时触发，可能导致排序不稳定
active_constraints = [k for k, v in constraints.items() if v > 0]
if len(active_constraints) > 2:
    print(f"多约束冲突: {active_constraints}")
```

### 5. 检查特征时效性

特征时效性问题：
- 特征缓存过期时间过短
- 特征更新频率过高
- 特征服务响应抖动

## 常见原因

| 原因 | 抖动特征 | 排查方式 |
|------|---------|---------|
| 实时特征波动 | 分数微小变化 | 打印特征值 |
| 探索权重过高 | 结果随机性 | 检查 exploration_rate |
| 多约束冲突 | 特定场景抖动 | 检查约束条件 |
| 特征时效性 | 时间相关抖动 | 检查缓存配置 |
| 随机种子问题 | 完全随机 | 检查随机种子设置 |

## 解决方案

### 方案一：特征平滑

```python
# rerank_engine.py
def smooth_realtime_features(feature_value, history_values, alpha=0.3):
    """平滑实时特征，减少抖动"""
    smoothed = alpha * feature_value + (1 - alpha) * history_values[-1]
    return smoothed
```

### 方案二：降低探索权重

```python
# 临时降低探索权重
exploration_rate = 0.05  # 原值 0.15
```

### 方案三：固定随机种子

```python
# 对于需要确定性的场景
import random
random.seed(request_id_hash)
```

### 方案四：添加结果缓存

```python
# 对同一请求短期内返回缓存结果
@cache(ttl=60)  # 缓存 60 秒
def execute_ranking(request_id):
    return compute_rank_score(...)
```
