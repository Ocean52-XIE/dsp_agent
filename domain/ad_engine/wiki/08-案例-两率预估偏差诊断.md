# 案例：两率预估偏差诊断

> **模块**: rate-prediction
> **标签**: 排障案例、两率、预估、校准
> **关键词**: pCTR、pCVR、预估、偏差、校准、calibration

## 问题现象

两率预估（pCTR/pCVR）出现系统性偏差：
- 预估值整体偏高或偏低
- 预估值与实际值偏差超过 10%
- 特定人群/场景预估异常

## 排查步骤

### 1. 计算预估偏差

```python
# 计算预估偏差（PCOC）
pcoc = sum(pctr) / sum(actual_ctr)

# 计算校准误差
calibration_error = abs(1 - pcoc)
```

偏差判断标准：
- PCOC 在 0.9-1.1 之间：正常
- PCOC > 1.1：预估偏高
- PCOC < 0.9：预估偏低

### 2. 分层分析

按不同维度分析预估偏差：

```python
# 按用户群体分析
group_by_user_type = df.groupby('user_type').agg({
    'pctr': 'mean',
    'actual_ctr': 'mean'
})

# 按广告位分析
group_by_slot = df.groupby('slot_id').agg({
    'pctr': 'mean',
    'actual_ctr': 'mean'
})

# 按时间分析
group_by_hour = df.groupby('hour').agg({
    'pctr': 'mean',
    'actual_ctr': 'mean'
})
```

### 3. 检查特征分布

检查特征分布是否发生漂移：

```python
# 检查特征分布
from scipy import stats

for feature in features:
    ks_stat, p_value = stats.ks_2samp(
        train_feature_dist[feature],
        online_feature_dist[feature]
    )
    if p_value < 0.05:
        print(f"特征漂移: {feature}, KS={ks_stat:.4f}")
```

### 4. 检查模型版本

确认模型版本是否正确：
- 模型是否按计划更新
- 是否存在版本回滚
- 模型热加载是否成功

### 5. 检查校准参数

检查 `rate_predictor.py` 中的校准参数：

```python
# 检查校准参数
calibration_params = {
    "ctr_bias": 0.0,
    "ctr_scale": 1.0,
    "cvr_bias": 0.0,
    "cvr_scale": 1.0,
}
```

## 常见原因

| 原因 | 症状 | 影响范围 |
|------|------|---------|
| 特征分布漂移 | 新人群/场景 | 局部 |
| 模型版本误切换 | 整体偏差 | 全局 |
| 校准参数不同步 | 系统性偏差 | 全局 |
| 特征工程变更 | 特定特征异常 | 局部 |
| 数据回传延迟 | 实际值不准 | 全局 |

## 解决方案

### 方案一：校准参数调整

```python
# rate_predictor.py
def calibrate_probability(raw_prob, bias, scale):
    """概率校准"""
    calibrated = (raw_prob + bias) * scale
    return max(0.0, min(1.0, calibrated))

# 根据偏差调整参数
if pcoc > 1.1:
    # 预估偏高，降低
    ctr_scale = 1.0 / pcoc
elif pcoc < 0.9:
    # 预估偏低，提升
    ctr_scale = 1.0 / pcoc
```

### 方案二：模型回滚

```bash
# 回滚到上一个稳定版本
curl -X POST http://model-service/rollback \
  -d '{"model_name": "pctr_model", "version": "v1.2.3"}'
```

### 方案三：特征修复

修复特征工程问题后重新部署。
